# Будущие фичи

Здесь храним идеи для проекта. У каждой идеи своя папка с описанием в `README.md`.

```text
features/
├── README.md
└── prebuilt-caddy-image/
    └── README.md
```

## Список идей

- [Готовый образ Caddy](prebuilt-caddy-image/README.md) · В работе

## Как добавить идею

1. Создай папку с коротким именем на английском в нижнем регистре. Разделяй слова дефисами, как в `features/prebuilt-caddy-image/`.
2. Скопируй шаблон ниже в `README.md` новой папки. Начни со статуса «Идея».
3. Добавь ссылку на карточку в список выше. При смене статуса обнови карточку и список.

Используй «Идея» для предложения, «В работе» после начала реализации и «Готово», когда проверки пройдены.
