# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [семантическое (SemVer)](https://semver.org/lang/ru/).

## Как версионируется проект

- Заметные изменения записываются в `[Unreleased]` по ходу разработки.
  Секция превращается в релиз `[X.Y.Z] - дата`, а тег `vX.Y.Z` создаётся
  по явной команде владельца.
- До версии 1.0 минорная версия может содержать новые функции и несовместимые изменения. Патч содержит исправления без изменения поведения.
- С версии 1.0 минорная версия добавляет обратно совместимые функции, патч
  содержит исправления, а мажорная версия — несовместимые изменения.

## [0.2.0] - 2026-11-22

### Добавлено

- Интерактивный мастер спрашивает каталог установки и предлагает продолжить
  прерванную установку или развёртывание из бэкапа с сохранённых ответов.
- Подбор SNI для REALITY при установке и перенастройке. Мастер и YAML
  могут проверить десять известных доменов или запустить Reality Scanner
  в подсети VPS. При неудачном автоподборе из YAML проверяются запасные
  имена из `reality_sni`.

### Изменено

- Интерактивный мастер показывает этапы установки и сводку перед применением.
  Для REALITY SNI он показывает ход проверки и таблицу подходящих хостов.
- Локальная песочница и GitHub Actions запускают тесты только на Debian 13.

### Исправлено

- Пользователь Docker получает доступ на чтение ко всему каталогу 3x-ui после установки.

## [0.1.0] - 2026-11-22

### Добавлено

- Интерактивная установка 3x-ui на Debian 12 и 13 и установка из YAML.
  Автоматическая настройка системного Docker и Docker Compose.
- Отдельные HTTPS-адреса панели и подписок. Сертификаты обслуживает 3x-ui
  с Certbot или Caddy с модулем Layer 4.
- TCP REALITY, прямой XHTTP REALITY и XHTTP через CDN. Встроенные
  JSON-шаблоны инбаундов можно заменить своими через YAML.
- Резервные копии SQLite, восстановление базы из файла, обновление
  компонентов и откат при ошибке проверки обновлённой панели.
- Диагностика HTTPS и VLESS-подключений с раздельными результатами
  для прямых запросов и запросов через Xray.
- Docker-песочница для Debian 12 и 13 и запуск тестов в GitHub Actions.
  Покрытие строк и ветвей проверяется отдельной задачей CI.
- Сборка и публикация образа Caddy для Linux amd64 и arm64 в GHCR при пуше
  тега после успешного прогона тестов. Установщик может скачать готовый образ
  или собрать его локально.
- Публикация GitHub Release после проверки образа с заметками из секции
  соответствующей версии в `CHANGELOG.md`.

### Изменено

- Ссылки установки и образа Caddy используют имя репозитория `easy-3x-ui`.
